│   ├── cfg.cpp                     # Task 2: CFG node implementations
│   ├── validator.cpp               # Task 3: Validation and semantic checking

Language choices:
  Tasks 1-4  →  C++17  (g++, no external libraries)
  Task 5     →  Soufflé Datalog + C++17 (Soufflé interoperates well with C++)
  Task 6     →  PDF paper (separate from this implementation)

Build:
  make          builds ./resir  (the main compiler binary)
  make test     builds and runs ./resir_test  (unit tests)
  make clean    removes built binaries
